## Ringkasan

Repositori ini berisi dokumen riset kecil untuk pra-skripsi tentang sistem monitoring kualitas udara berbasis IoT (ESP32 dengan sensor MQ-2, MQ-7, MQ-135, AHT10) yang mendeteksi anomali dan indikasi awal asap memakai LSTM Autoencoder secara unsupervised.
